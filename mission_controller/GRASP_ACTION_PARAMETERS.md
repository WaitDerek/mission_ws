# 抓取 Action 可调 ROS 参数名

来源：2026-09-30 rm1 当前运行中的 `/mission_controller`，通过 `ros2 param list /mission_controller` 读取。仅列名称，不改动任何参数。前两组是 GraspBox TF / DragBox TF 的独立参数；后几组是可能被抓取流程共用的参数，修改时要注意影响范围。`ros2 param set` 是否成功取决于参数类型与节点校验；即使设置成功，部分参数也可能仅在下次 Action 启动时读取。

```bash
source /rm_nvme/recordings/code/setup_mission_env.sh
ros2 param get /mission_controller <参数名>
ros2 param set /mission_controller <参数名> <新值>
```
