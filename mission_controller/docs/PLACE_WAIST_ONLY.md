# 动态放置：仅腰部弯腰，随后从实际位置下放

`place_box_test_dynamic_table_enabled=true` 的动态放置流程现在提前进入独立的腰部运动分支，不再调用腰部 Y/Z 工作空间搜索，也不生成或发送双臂弯腰补偿轨迹。该开关当前默认已开启；本次未改动配置数值。

执行顺序：

1. 读取当前携箱关系、双臂 TF 与腰部反馈。
2. 按双臂关节保持不动预测腰部运动时的箱底间隙。间隙不够时停止，不自动抬升。这只是抽样几何预检，不是完整碰撞验证。
3. 只发送一次腰部 MoveJ；不向两臂发送 MoveJ/MoveL。等待腰部位置和速度反馈到位。
4. 确认左右臂当前关节位置及速度稳定；此步骤只读取反馈，不发运动。
5. 使用 SDK Work-Fz 数据等待双臂力基线稳定，再固定一次双臂实际 TCP 起点及 arm base 变换；无运动、无清零。
6. 从固定起点沿共同 base_link -Z 等量累计下放；姿态保持，Y允许按左右Work轴成对调整以改善可达性。当前放置姿态下左Y+和右Y-是同一物理方向，不是开夹。先试原Y，必要时每段最多变化2mm；总范围±10cm，不要求走满。不在每步重设实测起点，不执行平均高度回拉。小超调不累积；若下一目标需要上抬则停止，不自动纠偏。每段结束记录实际下降进度。
7. 触底测力确认后，继续既有的触底后下放、外撤、Joint2 撤臂和回零流程。

双臂关节保持不动不等于箱子世界 Pose 不变：箱子会随腰部平移和旋转。这个变化与旧的保持箱体世界姿态方案不同。

## 力基线

以前仅取一次 8 帧窗口，波动超过 `support_threshold * 0.5` 立即失败。现在以 50 ms 间隔滚动采样，左右同一窗口均满足跨度要求后采用中位数。等待上限复用 `place_box_test_force_unload_baseline_timeout_sec`（默认 3 秒），超时仍停止，不盲目下降。

## 日志

- `PLACE_BOX_TEST_TARGETS`: `waist_only=true; arm_compensation=disabled; waist_workspace=not_used`
- `MOVING_PLACE_WAIST_ONLY`: 只动腰部，没有双臂补偿命令。
- `WAITING_FOR_PLACE_FORCE_STABILITY`: 首次窗口不稳定时等待，不发送运动。
- `DESCENDING_TO_TABLE`: 腰部完成后的实际末端下放阶段。
- `PLACE_DESCENT_REFERENCE`: 一次性固定的左右实测起点。
- `PLACE_DESCENT_PROGRESS`: 共同目标累计下降量、左右实测下降量及差值。
- 日志 `left_Work_y_offset`：下放起点以来左Work-Y累计偏移；当前镜像安装下右Work-Y数值相反。

不增加运动中的测力监督回调或受力转移分类；原有每段结束触底读力、松夹前承重确认继续保留。速度、触底后的额外下放等参数本次未改动。

dry-run 的目标仅为固定关节条件下的预测，不代表下放路径 IK/碰撞已验证。真实执行以弯腰后的 TF 为起点。旧的非动态示教放置模式保持不变；大小箱抓取及携箱回腰流程不在本次修改范围内。

测试在独立 ROS 域 197 和 localhost 运行，SDK/腰部调用均由测试替身代替；未运行实机放置。常规 merge-install 构建后需重启 Mission 生效。
